## 🎯 Quick Setup Instructions

### 1. Download OBS Studio (if not installed)
- Visit: https://obsproject.com/
- Download and install the latest version

### 2. Configure OBS Stream Settings

1. **Open OBS Studio**
2. **Go to Settings → Stream**
3. **Configure these settings**:
   - **Service**: Custom...
   - **Server**: `rtmp://localhost:1936/live`
   - **Stream Key**: [Copy from VisionWare streaming page]
   
### 3. Configure Video Settings (Recommended)

1. **Go to Settings → Video**:
   - **Base Resolution**: 1920x1080 (or your screen resolution)
   - **Output Resolution**: 1280x720 (recommended for smooth streaming)
   - **Downscale Filter**: Bilinear
   - **Common FPS**: 30

2. **Go to Settings → Output**:
   - **Output Mode**: Simple
   - **Video Bitrate**: 2500 Kbps (adjust based on internet speed)
   - **Audio Bitrate**: 160

### 4. Audio Setup

1. **Add Audio Input**:
   - Click **+** in Sources
   - Add **Audio Input Capture**
   - Select your microphone
   - Test audio levels (green/yellow is good, red is too loud)

### 5. Video Sources

1. **Camera Input**:
   - Click **+** in Sources
   - Add **Video Capture Device**
   - Select your webcam

2. **Screen Sharing**:
   - Click **+** in Sources
   - Add **Display Capture** or **Window Capture**
   - Choose what to share

### 6. Start Streaming

1. **In VisionWare**:
   - Go to Create Live Stream page
   - Choose "OBS Studio RTMP" mode
   - Click "Start Stream" to get ready
   - Copy the Stream Key provided

2. **In OBS Studio**:
   - Paste the Stream Key in Settings → Stream
   - Click **Start Streaming**

## 🔧 Troubleshooting

### Common Issues:

1. **"Failed to connect to server"**:
   - Make sure RTMP server is running on port 1936
   - Check if VisionWare backend is running
   - Verify Stream Key is correct

2. **Poor video quality**:
   - Reduce bitrate in OBS settings
   - Lower output resolution to 720p
   - Check internet upload speed

3. **Audio issues**:
   - Check microphone permissions
   - Test audio levels in OBS
   - Ensure Audio Input Capture is added

4. **High CPU usage**:
   - Use hardware encoding if available (NVENC/Quick Sync)
   - Lower video settings
   - Close unnecessary programs
